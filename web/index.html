ARK-II

ARK-II is a personal AI assistant built for the command line and browser. It listens, remembers, and acts — running entirely on your machine with cloud APIs only for intelligence. Designed for developers who want a real assistant, not a chatbot. Local memory, natural language, and zero friction. This is what Jarvis would look like if it lived in your terminal.

Overview

ARK-II is a hybrid AI assistant that lives in your terminal and browser. It combines local memory, natural language intent classification, and cloud intelligence to act as a persistent, always-available partner for daily workflows.

Technology
  • Core: Python 3.14
  • LLM: Groq (GPT-OSS 20B)
  • Speech-to-Text: Groq Whisper
  • Text-to-Speech: Google Gemini TTS
  • Wake Word: Vosk (local)
  • Backend: Flask + WebSockets
  • Frontend: Vanilla HTML/CSS/JS
  • Platform: Arch Linux + Hyprland
Real-World Problems
  • Remembering context across sessions
  • Managing reminders without opening apps
  • Quick voice-to-action without lifting hands
  • Summarizing active windows on demand
  • Reading and writing from the terminal
How It Works
  • User input (terminal, web, or voice)
  • Intent classified by NLP layer
  • Handler executes locally or calls AI
  • State written to data/state.json
  • Web UI polls state every 500ms
  • Response spoken via Gemini TTS
Project Structure
  • src/core — brain, NLP, state
  • src/features — memory, reminders, voice
  • src/utils — paths, helpers
  • web — dashboard + chat UI
  • data — memory, state, commands
  • server.py — Flask bridge
Conclusion

ARK-II is not a toy. It is a system designed to feel like a true extension of the user — persistent, useful, and quiet. Built on open tools, running on Arch Linux, and designed to scale with the user's needs.
